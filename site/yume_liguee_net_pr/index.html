これまでの事業

予約、内省シートの作成、当日の進行、イベント主催までをひとつで。株式会社Ligula（本社：神奈川県秦野市、代表取締役：今井 智紀）は、夢を言語化し現実にするための専用Webツール「夢を語る会 by Liguee」を公開しました。

本ツールは、イベントの参加予約から「やりたいことシート・アクションシート」の作成と提出、当日の画面共有やタイマーを備えたイベント進行、主催者向けの運営管理までを、ひとつのプラットフォームで行えるものです。

開発の背景

「夢を語る会」を開催・運営するなかで、参加者の事前課題（夢の言語化）の共有や、当日の進行とタイマーの管理、次回への案内など、複数のツールをまたぐことが体験を損ねていました。

そこで「夢を語り、叶えるためだけに特化した場所を作りたい」という想いから、参加者と主催者の双方にとって良い体験になるよう、ひとつにまとめたプラットフォームを作りました。

参加者向けの機能

  • やりたいことメーカー　1年後や将来に叶えたい夢を、カード形式で言語化します。
  • アクションシート　夢を現実にするための最初の一歩と、具体的な期日をセットで計画し、提出します。
  • 夢データの蓄積　過去のシートと参加履歴がマイページに残り、いつでも見返せます。
  • Ligula ID 連携　共通IDと連携し、当社のサービスへそのままアクセスできます。

主催者向けの機能

  • 画面共有のプレゼンテーションモード　参加者のシートを画面の中央に投影できます。
  • プレゼンタイマー　3分 / 5分 / 10分などを、ワンクリックでカウントダウンします。
  • 管理ダッシュボード　イベントの作成と複製、参加者一覧、課題の提出状況、一括メール配信までを一元管理します。

夢を叶える5つの段

  • やりたいことを言語化する
  • 夢を語る会に参加し、想いを共有する
  • 専用コミュニティで仲間を作る
  • Liguee のアパレルを着て、日常に落とし込む
  • 当社と協働する共創プロジェクトへ提案する

代表取締役 今井 智紀のコメント

「夢を語るということは、自分の内面と向き合い、未来の可能性を言葉にするプロセスです。今回のツールは、夢を発信する側はもちろん、それを受け止めてイベントを支える主催者の体験も、できるかぎり簡単にすることを目指しました。過去の夢やアクションプランが資産として溜まり、ここから新しい共創プロジェクトや仲間が生まれていく未来を楽しみにしています。」
