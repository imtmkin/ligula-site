方針・移行手順・要確認は一つ上の `../plan.md`。

## 構成（2026-11-03）

**トップはコーポレートサイト。**事業の中身はそれぞれの事業ページに置く。

| | 中身 |
| --- | --- |
| トップ | ロゴ → 一行 → 事業3つ（各ページへ） → 考え方 → プロジェクト → 会社概要 → 連絡先 |
| `service/web/` | ひと月の通り道、やること、経営者が使う時間（50分）、よくある質問 |
| `service/tarareba-board/` | 催しの日に起きること、画面4枚、使う場面、**概算を出す** |
| `service/event/` | 引き受ける範囲、考え方、**概算を出す** |

### 全ページで揃えていること

- **ヘッダーとフッターは全ページまったく同じ。**リンクはルート相対（`/service/web/` など）。
  ページごとにメニューが変わらないようにしてある（2026-11-03 の今井の指摘）。
- **画像の比率は3つだけ。** `.pic--band`（21:9）、`.pic--wide`（3:2）、`.pic--tall`（4:5）。
  どの画像も同じ枠に入れて `object-fit:cover`。当社の画面を見せるときだけ `.pic--screen` を足して、
  色をそのまま・切らずに（`contain`）出す。HTML の `width`/`height` は実寸に合わせてある。
- 地は白、主役は Ligula ブルー `#606F8C`、書体は Zen Kaku Gothic New 一本。

### 最初の画面の仕掛け

背景の格子は canvas にコードで描いている。**なぞるとたわみ、クリックすると割れる。**
クリックすると、その場から**ひびが6〜8本、折れながら走り**、ひびとひびのあいだの殻が板になって
外へ飛ぶ。中心には穴が開き、1.4秒かけて閉じる。当たった瞬間だけ画面が小さく震える。
同時に**「型破り！」が筆書体で、一文字ずつ書かれるように出て**、1.6秒ほどで消える。
出る場所と傾きは毎回ちがう（割った場所とは関係なく、画面の中からランダムに選ぶ）。
社名の意味「型破り」をそのまま画面にしたもの。`prefers-reduced-motion` が有効な端末では静止し、筆文字も出ない。

筆書体は Google Fonts の **Yuji Boku（佑字 墨）**。`&text=型破り！` で**その4文字だけに絞って**
読み込んでいるので、数KBしかない。トップページだけが読む。最初のクリックで間に合うように、
`site.js` の `inkFont()` で先に読ませている。別の筆書体にするなら Yuji Mai（佑字 舞。もっと崩れた字）。
差し替えは `index.html` の link と `style.css` の `.smash__w` の `font-family` の2か所。

**注意。**Claude Code のプレビュー枠は `requestAnimationFrame` を毎秒1コマまで絞るので、
止まって見える。実際のブラウザでは普通に動く。確認は `open http://localhost:8793/` で。

### 連打すると、全部割れる（隠し面）

**10回割ると格子が全壊する。**割るたびにばねが弱り、戻りが鈍くなる（2.5秒さわらないと1回ぶん戻る）。
10回目で金の閃光とともに格子が落ち、全画面の隠し面が出る。墨地に金。

中身は **「終えたもの、譲ったもの」**（20_20、Spalie、Ligula ID）。
サイトで一番強く言っている「効かないものはやめます」「数字の立たない事業を自分で終わらせた会社です」の、
**唯一の証拠**にあたる。実績として前に出す性質のものではないので、型を破った人だけが見られる場所に置いた。
クレドの言葉「選択と集中」もここに出る。

- 自動では遷移しない。「事業を見る」「これまでの事業」「閉じる」のボタンで本人が選ぶ。
- 閉じると格子が1.6秒かけて編み直される（`knit`）。型を破っても、また型はできる。
- `Escape` でも閉じる。`prefers-reduced-motion` の端末では、割れないので隠し面も出ない。
- 文言を変えるときは **筆書体のサブセットも直す**。`index.html` の Google Fonts の `&text=` と、
  `site.js` の `inkFont()` の両方。足りない文字は別の書体で出る。

### 概算見積り（`estimate.js`）

たらればボードとイベント受付のページに置いた。数を入れて要るものを選ぶと、その場で明細と合計が出る。
「保存して仮発注する」を押すと、**入力内容と明細を本文に書いた状態でメールソフトが開く**（送信は本人の操作）。
入力は `localStorage` に残る。サーバーは要らない。

**単価はすべて仮。`estimate.js` の `RATE` にまとめてある。公開前に今井が確定する**（`../plan.md` 要確認11）。
料金表はサイトに置いていない。数字が出るのは、この計算機の中だけ。

Netlify に載せたあとは、Netlify Forms（無料枠 月100件）に差し替えると、メールソフトを開かずに送れる。

## 理念の面 `#creed`(2026-11-04)

ミッション・理念・行動指針は **会社概要の表には入れない。**墨地の独立した面にしてある(今井の指示)。
全文と定義は `../../credo.md`。

- ミッションは筆書体(Yuji Boku)で大きく。**この面の文字はサブセットに含まれている必要がある。**
- **字の大きさに段差をつける。**ミッション(7.4vw) → 見出し `--s-head` → 値の名前(3.2vw) → 説明 `--s-body`。
  ここを詰めると「CSSが効いていない」と見える(2026-11-04 に一度やった)。
- 「実践値・経験値・絶対値」の **「値」だけ金色**。三つ縦に並ぶのが効いている。行動指針は名前の下に金色で「捨てる / 残す / 伸ばす」。
- 理念(実践値・経験値・絶対値)と行動指針(選択と集中・仕組み化・共伸)を2列。締めが「捨てて、残して、一緒に伸びる。」
- **「共伸（きょうしん）」は読みを括弧で添えたまま出す。**初見で読めない語なので。
- 箱で囲むとインスペクタの `card-rows` が出る。**余白だけで組んである。**
- 「リグる」はこの面の説明文、隠し面の「リグれ。」、Liguee の説明の3か所。
  **「型を破るために大事にすること」(コンフォートゾーン / お金 / ドリブン)はサイトに出さない。**
- 営業資料の会社案内にも三層が入っている。直すときは両方(`../../sales-decks.md`)。

  いまも提供していると読まれないため。
