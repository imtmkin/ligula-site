このサービスは、受託に軸を移したため新しい機能の開発を終えています。いまの事業は トップページ をご覧ください。

株式会社Ligula（本社：神奈川県秦野市、代表取締役：今井 智紀）は、当社が展開するアパレルブランドやWebサービスをひとつのアカウントで使えるようにする共通ID「Ligula ID」と、各サービスへアクセスできる「Ligula Portal」を公開しました。

公開の背景

私たちは「型を破り、世界を広げる」を掲げて活動しています。これまで独立していた各種WebサービスをひとつのIDでつなぐことで、より快適な体験を届けたいという想いから、開発に至りました。

Ligula ID でできること

  • ひとつのIDで、すべてのサービスへ　当社が提供するWebアプリケーションへのログインが、ひとつのアカウントで行えます。
  • サポーター機能　当社の活動や特定のプロジェクト（「夢を語る会」など）を直接応援できます。マイページでサポートの履歴が見られ、バッジが付きます。
  • 記録とランキング　Ligula ID でログインして各アプリを使うとスコアが記録され、ランキングに参加できます。

今後の展望

Ligula ID を土台に、アパレルの購入とWebサービスの利用が連携するポイントプログラムやコミュニティ機能の拡充を予定しています。
